# LåneApp

LåneApp er en mobilapplikation udviklet i React Native med Expo.

Appen gør det muligt for brugere at låne ting af hinanden. Brugere kan oprette ting, søge efter ting og sende låneanmodninger til andre brugere.

## Funktioner

- Opret bruger og log ind
- Opret ting til udlån
- Søg efter ting
- Send låneanmodninger
- Accepter eller afvis låneanmodninger
- Se egne ting og låneanmodninger

## Teknologier

- React Native
- Expo
- React Navigation
- Firebase Authentication
- Firebase Realtime Database

## Installation

Installer dependencies:

```bash
npm install
```

Start appen:

```bash
npx expo start
```

Appen kan herefter åbnes med Expo Go eller en simulator.

## Projektstruktur

```text
components/   Genbrugelige komponenter
database/     Firebase-konfiguration
screens/      Appens forskellige screens
styles/       Fælles styling
App.js        Navigation og app-struktur
```
