# LåneApp

LåneApp er en mobilapplikation udviklet i React Native med Expo i forbindelse med Godkendelsesopgave 2 i Innovation og Ny Teknologi.

Appen gør det muligt for brugere at låne ting af hinanden. Brugere kan oprette ting til udlån, søge efter andre brugeres ting og sende låneanmodninger.

## Funktioner

- Opret bruger og log ind
- Opret ting til udlån
- Søg efter andre brugeres ting
- Send låneanmodninger
- Accepter eller afvis låneanmodninger
- Se egne ting og låneanmodninger
- Gem og hent data via Firebase

## Teknologier

- React Native
- Expo
- React Navigation
- Firebase Authentication
- Firebase Realtime Database

## Installation

Installer dependencies:

```bash
npm install
```

Start appen:

```bash
npx expo start
```

Appen kan herefter åbnes med Expo Go eller en simulator.

Der kræves en internetforbindelse, da appen anvender Firebase til brugerlogin og lagring af data.

## Arbejdsfordeling

LåneApp er udviklet i fællesskab af Amra og My.

Vi har arbejdet tæt sammen om størstedelen af applikationen, herunder idéudvikling, programmering, test og fejlfinding. Derfor har vi begge bidraget til koden på tværs af projektets forskellige filer, men primært på samme computer.

Vores fokusområder har dog været lidt forskellige:

- **My:** Har især haft fokus på appens funktionalitet, herunder Firebase, brugerhåndtering, søgefunktionen og låneanmodninger.
- **Amra:** Har især haft fokus på appens visuelle udtryk, styling og de afsluttende designmæssige justeringer.

Vi har desuden samarbejdet om brugerinddragelsen og forbedringerne af appen på baggrund af feedback.

De skriftlige rapporter er udarbejdet individuelt.
